      关于 AgentLab

      版本 1.0

      AgentLab 是一个本地优先、半托管的个人 Agentic 软件开发工作流平台。采用双脑架构 (DeepSeek 大脑 + Codex/Qwen 执行)，将规划、路由、预算、执行、验证、审计和归档分离为独立的 Agent 阶段。

      • 8 个 Agent 协作，按需路由
      • Token 预算治理和循环检测
      • 完整审计追踪 (每条任务 14+ 个文件)
      • 零依赖纯静态 Web UI
      • 跨平台桌面 App (macOS / Linux / Windows)
      • 结构化编辑块 — 任何 LLM API 可直接编辑文件

      快速入门

      1. 下达任务 — 在顶部输入框用自然语言描述你的需求
      2. Supervisor 规划 — AgentLab 大脑自动分配路由和预算
      3. Agent 执行 — 各 Agent 按序协作完成分析和编码
      4. Coder 编辑 — 结构化编辑块自动应用到文件系统
      5. 审计归档 — TesterAuditor 验证，Archivist 更新项目记忆

      CLI 常用命令

      # 初始化新任务
./agentlab.sh init-task --project AgentLab --task-id task_0010

# 生成工作流计划
./agentlab.sh prepare --project AgentLab --task-id task_0010 --write-plan

# 执行 Agent (大脑层)
./agentlab.sh run-agent Supervisor --project AgentLab --task-id task_0010 --execute

# 查看状态
./agentlab.sh status --project AgentLab --task-id task_0010

# 启动 Web UI
python3 web_ui/server.py

# 启动桌面 App
python3 agentlab_app.py
